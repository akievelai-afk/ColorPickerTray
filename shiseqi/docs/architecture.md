# 架构文档

## 技术选型
- 推荐语言：C#
- 推荐 UI 框架：WPF 或 WinUI 3
- 主要原因：原生 Windows 性能好、系统托盘与屏幕采样能力稳定、体积适中

## 系统模块
1. 启动与托盘模块
   - 系统托盘图标与上下文菜单
   - 启动时最小化到托盘
   - 托盘菜单字段：启动拾色、打开历史、设置主题、退出
2. 热键模块
   - 注册全局热键（默认 F1，可自定义）
   - 监听热键唤醒拾色模式
3. 拾色模块
   - 屏幕颜色采样逻辑
   - 捕获当前鼠标位置像素颜色
   - 边缘判断：右侧自动改左下角显示提示框
4. UI 提示模块
   - 浮动提示窗：放大镜、色轮、颜色预览、HSV 值
   - 显示当前颜色的 RGB/HSV/HEX 格式
5. 复制与格式模块
   - 当前选中格式复制到剪贴板
   - 支持复制所有格式
   - 可在设置中选择显示格式
6. 历史与导出模块
   - 历史数据存储（本地轻量文件或应用配置文件）
   - 保存上限 50 条
   - CSV 导出与清空功能
7. 主题与设置模块
   - 主题配置：淡蓝、深色、浅色
   - 热键自定义、显示格式选择等设置

## 数据存储方案
- 本地配置文件：建议使用 JSON 或 XML 存储设置与历史
- 历史记录保存字段：时间、颜色值(HSV/RGB/HEX)、备注（可选）
- CSV 导出时输出字段：序号、时间、HSV、RGB、HEX

## 交互流程
1. 启动时最小化到托盘
2. 用户按 `F1` 或自定义热键
3. 进入拾色模式，显示浮动提示
4. 拾色后按 `C` 复制
5. 记录历史，更新历史面板
6. 用户通过托盘菜单打开历史或设置

## 安全与稳定
- 避免系统托盘图标失效
- 捕获全局热键时处理冲突
- 拾色器退出时释放资源
- 防止历史记录文件损坏
