# 需求文档

## 项目目标
开发一个运行于 Windows 的轻量级系统托盘屏幕拾色器，提供快速取色、实时显示颜色信息、历史记录与导出功能。

## 核心功能
1. 系统托盘小程序
   - 软件启动默认最小化到系统托盘
   - 托盘右键菜单包含“启动拾色”“打开历史”“设置主题”“退出”
2. 热键启动
   - 默认热键：F1
   - 支持用户自定义热键
3. 屏幕拾色
   - 按热键进入拾色模式
   - 鼠标移动时实时拾取指针下方颜色
   - 支持覆盖指针活动范围内的任意屏幕像素
4. 拾色提示
   - 指针右下角显示放大镜和色轮
   - 当鼠标位于屏幕最右侧时自动改为左下角显示
   - 显示颜色预览方块和当前颜色 HSV 值
   - 显示颜色在色轮上的位置
5. 颜色格式
   - 默认面板显示 HSV
   - 支持用户在设置中添加显示 RGB、HEX 等格式
   - 支持“只复制当前格式”和“复制所有格式”的切换
6. 复制与剪贴板
   - 拾色后按 `C` 复制颜色值到剪贴板
   - 默认复制当前选中格式，支持复制所有格式
7. 历史记录
   - 保存最多 50 条颜色记录
   - 提供历史颜色板展示
   - 支持 CSV 导出历史记录
   - 支持清空历史记录
8. 主题支持
   - 支持默认淡蓝主题、深色和浅色主题

## 非功能需求
- 界面简洁、轻量、直观
- 操作稳定，响应及时
- 资源占用低，运行安全
- 兼容常见 Windows 版本
