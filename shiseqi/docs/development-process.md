# 开发流程

## 迭代计划
1. 阶段 1：目录与文档搭建
   - 完成项目结构与规范文档
   - 确认技术方案与功能范围
2. 阶段 2：托盘与热键架构
   - 实现应用启动、最小化到托盘
   - 实现托盘菜单与全局热键唤醒
3. 阶段 3：拾色核心实现
   - 实现屏幕像素采样
   - 实现浮动提示框和边缘显示切换
4. 阶段 4：颜色格式与复制历史
   - 实现格式显示与复制功能
   - 实现历史记录、CSV 导出、清空功能
5. 阶段 5：主题与设置面板
   - 实现主题切换与热键/格式设置
6. 阶段 6：验证与发布
   - 进行稳定性测试
   - 完成打包发布准备

## 验收标准
- 启动后默认最小化到托盘
- `F1` 可唤醒拾色模式
- 拾色提示框实时显示当前颜色
- `C` 能正确复制颜色值到剪贴板
- 历史记录可保存、导出 CSV、清空
- 主题切换效果可用
- 托盘菜单能正常操作

## 日志与进度记录
- 每天创建新的 `dev-daily/YYYY-MM-DD.md`
- 推荐记录字段：
  - 完成事项
  - 今日待办
  - 风险/问题
  - 明日计划

## 风险管理
- 热键冲突导致无法唤醒：提供自定义热键
- 屏幕采样权限问题：使用原生 Windows API 实现
- 历史文件损坏：增加备份与容错机制

## 交付节点
- 原型验证：托盘、拾色、复制、历史基础功能可用
- MVP 完成：支持主题、设置、CSV 导出
- 发布准备：打包、安装与用户说明文档完成
