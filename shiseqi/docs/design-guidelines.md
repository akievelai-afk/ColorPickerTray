# 设计规范

## 设计目标
- 简洁、直观、轻盈
- 主要颜色使用淡蓝色，辅以中性色背景
- 强调拾色交互与实时反馈

## 视觉风格
- 主色：淡蓝色（用于按钮、选中状态、强调线条）
- 辅助色：浅灰、白色、深灰
- 文本：高对比正文与次级说明
- 元素圆角：适度圆角，使界面柔和
- 间距：保持适当留白，避免拥挤

## UI 组件
### 系统托盘菜单
- 启动拾色
- 打开历史
- 设置主题
- 退出

### 拾色提示框
- 放大镜视图：显示鼠标周围 5x5 或 7x7 像素放大效果
- 色轮图标：直观表示当前颜色位置
- 颜色预览方块：显示当前颜色填充
- 颜色值文本：默认显示 HSV，可切换显示更多格式

### 历史面板
- 颜色块列表展示历史记录
- 每条记录显示：颜色预览、小文本格式值、时间
- 支持导出 CSV 与清空按钮

## 交互规范
- 默认使用 `F1` 进入拾色模式
- 使用 `C` 复制当前格式
- 用户按 Esc 或再次按热键退出拾色模式
- 鼠标靠近屏幕右侧时，提示框自动切换到左下方向，保证不遮挡视野

## 主题规范
- 默认主题：淡蓝色调
- 深色主题：深背景 + 淡蓝强调色
- 浅色主题：浅背景 + 饱和淡蓝色强调

## 可访问性要点
- 保持文本对比度足够
- 交互元素大小适中
- 提示信息清晰，避免复杂动画
