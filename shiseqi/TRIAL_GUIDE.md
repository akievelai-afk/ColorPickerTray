# ColorPickerTray 试用指南

感谢您试用 ColorPickerTray！这是一款 Windows 屏幕拾色器工具。

## 系统要求
- Windows 10 或更高版本
- .NET 6 Runtime（如果未安装，会提示安装）

## 快速开始

1. **解压文件**  
   将 `ColorPickerTray.zip` 解压到任意位置

2. **运行应用**  
   双击 `ColorPickerTray.exe` 启动应用

3. **托盘图标**  
   应用启动后会在系统托盘（右下角）显示一个彩色方块图标

## 使用方法

### 激活拾色器
- **按 `F1`** 打开拾色器覆盖窗口
- 窗口会跟随鼠标光标实时显示当前色值

### 拾色器窗口功能
| 区域 | 说明 |
|------|------|
| 左侧 | 当前颜色预览、放大镜、复制格式按钮 |
| 右侧 | 色轮（选择色相）、三个滑条（HSV 调整） |

### 获取颜色值
- **左键单击** 或 **C 键**：复制当前颜色（使用选定的格式）
- **支持格式**：HEX、RGB、HSV（可在设置中选择）
- 窗口右侧显示数值

### 关闭拾色器
- **右键单击**或按 **Esc** 关闭拾色器窗口

### 托盘菜单
- 右键点击系统托盘图标可打开菜单
- **设置**：调整热键、显示格式、主题等
- **退出**：关闭应用

## 常见问题

**Q: 按 F1 没有反应？**  
A: 确保应用已启动（检查系统托盘）。如果仍无反应，可在设置中修改热键。

**Q: 拾色器窗口位置不合适？**  
A: 窗口会自动避开屏幕边界，确保始终可见。移动鼠标到不同位置会自动调整。

**Q: 复制了什么格式的颜色？**  
A: 检查窗口右下角的格式选择下拉框。可点击切换 HEX、RGB、HSV 等格式。

**Q: 颜色历史在哪里？**  
A: 在设置窗口的"历史"标签页查看。可导出为 CSV 文件。
